햄깅이의 씨앗창고 정산하기

find · filter · map · localStorage 연습 🌰

📦 창고 데이터

const seeds = [ { id: 1, name: "해바라기씨", qty: 12, eaten: false }, { id: 2, name: "호박씨", qty: 3, eaten: true }, { id: 3, name: "땅콩", qty: 8, eaten: false }, { id: 4, name: "잣", qty: 1, eaten: false } ];

🎯 미션

  1. find id가 3인 씨앗 객체를 찾아 출력하기
  2. filter 아직 안 먹은(eaten: false) 씨앗만 골라 새 배열 만들기
  3. filter + map 수량(qty)이 5개 이상인 씨앗의 이름만 배열로 뽑기
  4. map 모든 씨앗 이름 뒤에 🌰 붙인 새 배열 만들기 (예: "땅콩🌰")
  5. reduce / 합 안 먹은 씨앗들의 총 수량 합계 구하기
  6. localStorage seeds를 저장하고, 다시 불러와서 출력하기
⭐ 도전: "땅콩"을 먹은 상태(eaten: true)로 바꿔 저장하고, 다시 불러왔을 때도 그 상태가 유지되는지 확인하기
(find로 찾아 수정 → JSON.stringify로 저장 → JSON.parse로 불러오기)

🔑 막히면 펼쳐봐 (정답)

1번 — find로 id 3 찾기
const found = seeds.find(s => s.id === 3); console.log(found); // find는 조건에 맞는 "객체 1개"를 돌려줌
2번 — filter로 안 먹은 씨앗
const notEaten = seeds.filter(s => s.eaten === false); console.log(notEaten); // filter는 조건에 맞는 것들의 "새 배열"을 돌려줌
3번 — filter + map 체이닝
const bigNames = seeds .filter(s => s.qty >= 5) // 5개 이상만 거르고 .map(s => s.name); // 이름만 뽑기 console.log(bigNames); // ["해바라기씨", "땅콩"]
4번 — map으로 🌰 붙이기
const withNut = seeds.map(s => s.name + "🌰"); console.log(withNut); // 개수는 그대로, 모양만 바꿔서 새 배열
5번 — 안 먹은 씨앗 총 수량
const total = seeds .filter(s => !s.eaten) .reduce((sum, s) => sum + s.qty, 0); console.log(total); // 12 + 8 + 1 = 21 // reduce가 아직 어렵다면 이렇게도 가능: let sum = 0; seeds.filter(s => !s.eaten).map(s => sum += s.qty); console.log(sum);
6번 — localStorage 저장 / 불러오기
localStorage.setItem("seeds", JSON.stringify(seeds)); // 객체배열 → 문자열 const loaded = JSON.parse(localStorage.getItem("seeds")); // 문자열 → 객체배열 console.log(loaded);
⭐ 도전 — 땅콩 먹고 저장 후 유지 확인
const peanut = seeds.find(s => s.name === "땅콩"); // find로 찾고 peanut.eaten = true; // 수정 localStorage.setItem("seeds", JSON.stringify(seeds)); // 저장 const loaded = JSON.parse(localStorage.getItem("seeds")); // 다시 불러오기 console.log(loaded.find(s => s.name === "땅콩")); // eaten: true 로 유지됨!
